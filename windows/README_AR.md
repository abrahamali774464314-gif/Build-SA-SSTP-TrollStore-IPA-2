# SA SSTP Windows 1.0.0

برنامج Windows مستقل بصيغة EXE، يستعمل عميل SSTP المدمج في Windows 10/11 x64. لا يحتاج تثبيت .NET منفصلاً في النسخة المنشورة.

- نفس 49 سيرفرًا من كتالوج تطبيق الهاتف، مع الإضافة والتعديل والحذف والبحث والتصفية.
- حساب مستقل لكل سيرفر محفوظ عبر Windows Credential Manager؛ لا تُكتب كلمات المرور في JSON ولا تُمرر لسطر الأوامر.
- حفظ الاختيار والمصادقة والإعدادات محليًا، واستيراد وتصدير السيرفرات اليدوية فقط دون أسرار.
- اتصال وفصل حقيقيان باستخدام Windows RAS وSSTP، مراقبة حالة الاتصال، إعادة اتصال اختيارية محدودة، وتصغير إلى شريط المهام.
- اسم DNS هو عنوان الاتصال واسم الشهادة، والمنفذ المخصص يُلحق باسم المضيف. IP المدرج مرجع فقط. لا يُعدّل hosts ولا يُعطّل TLS.
- لا تُغيّر ملفات VPN الأخرى؛ أسماء الملفات التي يديرها البرنامج تبدأ بـ SA-SSTP-.

## التشغيل
افتح SA_SSTP_Windows.exe، اختر السيرفر، أدخل الحساب مرة واحدة وفعّل التذكر ثم اضغط اتصال. يحتاج السيرفر إلى DNS صحيح وشهادة موثوقة ومصادقة متوافقة. افتح قائمة أيقونة البرنامج بجوار الساعة للخروج أو الفصل.

## اعتماد الإصدار
بناء Release واختبارات حفظ السيرفرات والتحقق من البيانات تُنفذ في GitHub Actions. يلزم تأكيد الاتصال الحقيقي على Windows 10/11 بحساب مصرح به، والتحقق من تمرير الإنترنت عبر النفق، واستعادة الحساب بعد الإغلاق، قبل وصف التشغيل بأنه معتمد نهائيًا. الملف غير موقّع بشهادة ناشر تجارية؛ قد يعرض SmartScreen تحذيرًا. لا يتم تعطيل ميزات الحماية.
