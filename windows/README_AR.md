# SA SSTP Windows 1.0.2

برنامج Windows مستقل بصيغة EXE، يستعمل عميل SSTP المدمج في Windows 10/11 x64. لا يحتاج تثبيت .NET منفصلاً في النسخة المنشورة.

- نفس 49 سيرفرًا من كتالوج تطبيق الهاتف، مع الإضافة والتعديل والحذف والبحث والتصفية.
- حساب مشترك لجميع السيرفرات محفوظ عبر Windows Credential Manager؛ لا تُكتب كلمات المرور في JSON ولا تُمرر لسطر الأوامر.
- حفظ الاختيار والمصادقة والإعدادات محليًا، واستيراد وتصدير السيرفرات اليدوية فقط دون أسرار.
- اتصال وفصل حقيقيان باستخدام Windows RAS وSSTP، مراقبة حالة الاتصال في الخلفية دون تعطيل عناصر الواجهة، إعادة اتصال اختيارية محدودة، وتصغير إلى شريط المهام.
- اسم DNS هو عنوان الاتصال واسم الشهادة، والمنفذ المخصص يُلحق باسم المضيف. عند فشل DNS أو اختلافه عن IP المحفوظ، يستخدم التطبيق ربطًا مؤقتًا للسيرفر المحدد داخل hosts، بعد الموافقة وبصلاحيات المسؤول. يحذف سطره الخاص بعد محاولة الاتصال، ويزيل بقاياه عند تشغيله مجددًا كمسؤول إذا انتهت العملية فجأة. لا يغيّر ربطًا موجودًا ولا يعطّل TLS.
- لا تُغيّر ملفات VPN الأخرى؛ أسماء الملفات التي يديرها البرنامج تبدأ بـ SA-SSTP-.

## التشغيل
افتح SA_SSTP_Windows.exe، اختر السيرفر، أدخل الحساب مرة واحدة وفعّل التذكر ثم اضغط اتصال. يحتاج السيرفر إلى شهادة موثوقة ومصادقة متوافقة. إذا تعذر DNS، شغّل التطبيق كمسؤول ووافق على الربط المؤقت. لا يلزم تعديل hosts يدويًا. افتح قائمة أيقونة البرنامج بجوار الساعة للخروج أو الفصل.

## اعتماد الإصدار
بناء Release واختبارات حفظ السيرفرات والتحقق من البيانات تُنفذ في GitHub Actions. يلزم تأكيد الاتصال الحقيقي على Windows 10/11 بحساب مصرح به، والتحقق من تمرير الإنترنت عبر النفق، واستعادة الحساب بعد الإغلاق، قبل وصف التشغيل بأنه معتمد نهائيًا. الملف غير موقّع بشهادة ناشر تجارية؛ قد يعرض SmartScreen تحذيرًا. لا يتم تعطيل ميزات الحماية.

## تحديث 1.0.2
حساب مشترك لجميع السيرفرات: عند الترقية يُنقل الحساب المحفوظ لآخر سيرفر مختار إن وجد، أو الحساب الوحيد إذا لم يوجد اختلاف بين الحسابات المتاحة؛ إذا تعددت الحسابات المختلفة دون حساب مختار يُطلب إدخال الحساب المشترك مرة واحدة. لا تُحذف الحسابات القديمة تلقائيًا لكن الإصدار الجديد لا يستخدمها بعد الترقية. زر حفظ الحساب للجميع أو الاتصال مع تفعيل التذكر يحفظ الحساب المشترك. زر الاتصال والحالة ثابتان أسفل النافذة. لا يُوقف فحص الحالة الدوري عناصر الواجهة.
